# Kana — New Tab Practice

A no-build Chrome extension that turns each new tab into a short hiragana flashcard session.

## Install in Chrome

1. Open `chrome://extensions`.
2. Turn on **Developer mode**.
3. Choose **Load unpacked** and select this `kana-new-tab` folder.
4. Open a new tab to start practicing.

## How it works

- Learn all 46 basic hiragana, one at a time, with an original mnemonic, a bundled photo, and a Japanese example word.
- Guess the sound, reveal the answer, then choose **Again** or **Got it**.
- Reviews are scheduled locally: missed cards return in 10 minutes; correct cards return after 1, 3, 7, 14, 30, then 60 days.
- Photos are bundled for offline use; credits and licenses are listed in `PHOTO-CREDITS.md`.
- Press **Space** to reveal, then **1** for Again or **2** for Got it.
- Progress is saved in this Chrome profile. No account, network requests, or build step required.

The card for を notes its modern pronunciation as “o.” This first version covers the 46 basic kana; voiced sounds and combinations can be added later.
